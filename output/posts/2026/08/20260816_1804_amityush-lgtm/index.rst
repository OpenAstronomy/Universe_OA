    <p></p><h1>A Lot Learned, A Lot More to Do 🚀</h1><p>And just like that, <strong>12 weeks of GSoC are over!</strong></p><p>The last two weeks have been quite different from the earlier ones. There was a lot of finishing up, reviewing, fixing things that broke along the way and making sure the bigger pieces of the project were coming together properly.</p><p>Here's what I've been up to.</p><h2>Learning to Write Less Code 😅</h2><p>One of the biggest lessons from these weeks actually came from a code review.</p><p>I had previously added some custom methods for getting time and frequency profiles from a spectrogram. The code worked, but there were some change of plans, during review we realized that <b><code>ndcube</code> </b>already provided the functionality needed to achieve the same thing.</p><p>So instead of keeping the extra code, I removed it and focused on showing users how to use the existing <b><code>ndcube</code> </b>methods.</p><p>It was a really good reminder that <strong>adding more code isn't always the right solution</strong>.</p><p>Sometimes the better approach is to make better use of what already exists.</p><hr /><h2>Making the Examples More Useful 📚</h2><p>After removing the custom wrappers, I wanted to make sure users could still easily understand how to perform these operations.</p><p>I worked on a Sphinx-Gallery example showing how to crop spectrograms and extract profiles using the&nbsp;<code>ndcube</code> API.</p><p>The example covers cropping by time, cropping by frequency, combining both and extracting 1D profiles.</p><p></p><div class="separator" style="clear: both; There's always testing, documentation, reviews and cleanup.</p><hr /><h2 class="PDq2pG_selectionAnchorContainer">12 Weeks Done… But Not Finished Yet 🚀<span class="PDq2pG_selectionAnchor"></span></h2>
    <p>And that's officially <strong>12 weeks of GSoC done!</strong></p>
    <p>Looking back, it's honestly hard to believe how much I've learned in these three months. I started with a lot of questions about the codebase and now I'm working on things like the architecture of the <code>SpectrogramFactory</code>, <code>ndcube</code> integration, documentation, testing and all the little things that come with maintaining an open-source project.</p>
    <!-- TEASER_END -->
    <p>But even though the official GSoC period has come to an end, <strong>there's still plenty left to do.</strong></p>
    <p>There are reviews to finish, things I'd like to improve and ideas that I didn't get the chance to explore fully during these 12 weeks.</p>
    <p>And honestly, I'm still very excited to keep working on <code><b>radiospectra</b></code>.</p>
    <p class="">One of the biggest things GSoC gave me wasn't just the code I contributed, but the feeling that I can actually be part of an open-source project and continue contributing even after the program ends.</p>
    <p>So this isn't really a goodbye.</p>
